# Vision

Longer-term ideas and direction for EliteMUD-CS. Nothing here is scheduled work.

**How this folder relates to the others:**

| Folder | What goes there |
|---|---|
| `docs/vision/` | Ideas and direction we want to keep in mind. Not committed to. |
| `docs/plans/` | Work we've decided to do, broken into tasks. |
| `docs/reports/` | Findings from investigations and audits. |
| `docs/roadmap.md` | What's done, what's next, what's left. |

When an idea here turns into real work, write a plan in `docs/plans/` and link back to the idea.
